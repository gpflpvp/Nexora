# Features

**All features listed here are planned and subject to implementation and testing.**

| Area | Planned experience |
| --- | --- |
| Home | Discover featured entertainment and browse categories. |
| Anime | Explore anime films and episodic productions. |
| Movies | Browse films and open detailed title pages. |
| TV shows | Explore shows, seasons, and series. |
| Episodes | Browse seasons and select individual episodes. |
| Playback | Watch supported media through an in-app player. |
| Search | Search the available catalog for titles. |

Feature availability depends on release notes and completed verification, not this planning document. The app will only integrate content sources with appropriate permissions and distribution rights.
