# Android installation

**No APK is available yet.** Only install files from a published Nexora release.

When a release is available:

1. Open the repository's **Releases** section.
2. Select the intended release and review its notes and supported Android versions.
3. Download the APK file from **Assets**.
4. On your Android device, allow installation from your chosen browser or file manager if prompted.
5. Verify the expected application identity and requested permissions before installing.

Debug builds and unverified downloads should not be presented as public releases. Do not install APK files from unofficial mirrors.
